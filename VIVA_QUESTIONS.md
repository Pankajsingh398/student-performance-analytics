# Quick Viva Preparation

1. **What is the project?** A dashboard to analyze student marks, attendance and study hours.
2. **Why Python?** It has simple syntax and strong data-analysis libraries.
3. **What is Pandas?** A library for reading, cleaning, filtering and analyzing tabular data.
4. **What is NumPy used for here?** Numeric operations and assigning rule-based categories.
5. **What is Streamlit?** A Python framework to build interactive data apps quickly.
6. **What is Matplotlib?** A plotting library used for charts.
7. **What is CSV?** Comma-separated values, a simple tabular data file format.
8. **How is risk assigned?** The demo flags High risk when attendance is below 65% or marks below 35; Medium for attendance below 75% or marks below 50; otherwise Low.
9. **Is this a real ML prediction?** No. The current version uses transparent rules for a study-pattern estimate. A validated ML model would need suitable data, training, testing and evaluation.
10. **What are limitations?** Synthetic data, simple rules, and no authentication/database in the first version.
11. **What would you add next?** Database integration, authentication, PDF export and a properly evaluated ML model.
12. **What did you learn?** Data cleaning, metrics, visualization, dashboard design and handling CSV uploads.
